# Cepheid Light Curve Processing Pipeline

An automated, Python-based data engineering pipeline designed to ingest, clean, and analyze astronomical time-series data. This tool processes raw photometric measurements of Cepheid variable stars, extracts their primary pulsation frequency from unevenly sampled data, and generates a phase-folded light curve.

## The OGLE Database
The data processed by this pipeline is sourced from the **Optical Gravitational Lensing Experiment (OGLE)**, a long-term sky survey project operated by the University of Warsaw. OGLE provides comprehensive and high-quality photometric catalogs, particularly for variable stars located in the Magellanic Clouds.

## Lomb-Scargle

In standard digital signal processing, extracting the dominant frequency of a signal is typically done using a Fast Fourier Transform (FFT). However, FFT strictly requires evenly spaced data points. 

Astronomical data is inherently chaotic and non-uniform due to the Earth's rotation (day/night cycles), weather conditions, and seasonal observation gaps. To solve this, the pipeline utilizes the **Lomb-Scargle Periodogram**. Instead of a standard Fourier transform, Lomb-Scargle performs a weighted least-squares fit of sinusoidal models across a defined frequency grid. This allows the algorithm to accurately detect periodicity even in heavily fragmented time-series data while properly weighting data points based on their measurement errors.

## How to Use

### 1. Prerequisites
Ensure you have the required scientific libraries installed. The pipeline relies heavily on `astropy` for astronomical statistics and periodogram generation.

```bash
pip install pandas numpy matplotlib astropy
```

### 2. Running the Pipeline
Simply execute the main script. By default, it will download the photometric data for OGLE-LMC-CEP-0001 directly from the OGLE-IV public FTP archive and run the full analysis.

```bash
python pipeline.py
```

Top Panel (Cleaned Time Series): Displays the raw magnitude measurements over thousands of time. Sigma-clipping has been applied to remove extreme outliers and instrumental noise. 

Middle Panel (Frequency Analysis): The Lomb-Scargle periodogram. The prominent spike represents the mathematically most probable pulsation period (e.g., $P \approx 0.3068$ days). The search parameters are configured to avoid daily aliasing caused by the 24-hour observation cycle.

Bottom Panel (Phased Light Curve): The final folded curve. The chaotic time-series data is collapsed into a single, normalized pulsation phase $[0.0, 2.0]$.
